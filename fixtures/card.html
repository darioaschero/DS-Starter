1 · Size axis — sm / md / lg + no attribute

The no-attribute card must render identically to data-size="md" (base rule is the only implementation of the default).

Default card

Must equal the md card in every computed value.

2 · Unsupported value — data-size="xl"

xl is not card vocabulary. No selector matches it, so the base rule (md) wins. Graceful fallback is not validation — a linter would report it.

Unsupported size

Renders exactly as md.

3 · Nested components — buttons inside actions

The buttons are real components with their own data-part="label" spans. Card part selectors must not reach them. (While the button component is a stub the buttons render mostly unstyled — containment is still fully testable.)

4 · Card in card

Outer card is lg (title heading-md, padding space-6). The inner card carries no size attribute, so its parts must resolve from the inner card's own md channels — outer part rules and outer channel values must not reach in.

5 · Wrapped part — title inside a plain wrapper

Wrapped title

The title above sits inside an extra plain <div>, not as a direct child of the card root.

Result with the shipped technique (direct-child combinators): the wrapped title is deliberately not styled — it falls back to UA heading styles (700 weight instead of 600, 18.72px instead of 19px). The recommended contract: parts sit as direct children of the card root; wrap content inside a part, never around one. The tested @scope alternative styles wrapped parts at any depth; see docs/findings/card.md.
